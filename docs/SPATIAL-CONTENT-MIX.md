# 内容适配空间混音

目标：在既有本地立体声→HDemucs四轨→DSP候选→声场→7.1.4/HRTF链中，用实际测量替代固定分轨名字决定空间角色。保留源文件、旧场景及可回退的候选，不把文件完整性或统计数值当听感通过。

## 选择与边界

- 本轮采用现有NumPy/SciPy/FFmpeg测量与可追溯规则：低频占比、RMS、活动比例、crest和单声道抵消/Side信息。无新权重、无外发音频。它识别声学特征候选，不识别具体乐器。
- 非零素材若无法取得有效真峰测量，自动混音直接拒绝该次处理；不能用采样峰替代真峰，也不把测量失败当作零峰值继续生成候选。
- CLAP/PANNs可作为后续语义辅助，但须先有离线资产、许可与本机验证；相似度或类别分数不直接当可靠概率。Essentia的loop分类输入域及部分权重非商业许可需要单独核实。
- SPHERE等自动上混研究启发主体居中、声场分布及电平平衡的分项检查，不采用单一综合分数无限优化；本轮阈值为项目启发式，不冒充论文复现或Dolby标准。

## 实现范围

1. 新增纯函数内容规划器：按观测id绑定，而非列表位置或分离器命名；返回静态场景候选与逐轨证据。低频/能量主体优先前方耳平面；满足持续与宽度证据的次要声部可提出后方/上层候选；安静或证据不足不强制发声/移动。
2. 从M/S能量关系保留宽度风险提示；不自动把带明显Side的轨收成0°。有显著重建残差的复合载体限制在前方，不把伪影自动绕到后上方。无自动压缩、增益拉齐或LFE填充。
3. 作为“内容适配”显式候选加入现有mix/apply；保留原布局选项及回退。绑定候选对应的analysisHash，保存独立内容报告。旧项目读取不自动改写。
4. 修正clarity提案中zip列表顺序绑定；移除仅因other/vocals名字才能进入的低频检查，保持同内容处理一致。
5. 协调器可选择内容适配，收集报告与7.1.4逐通道包。用本机已有真实分轨制作独立新项目、响度匹配对照及文件校验；不覆盖旧版本。

立体声宽度使用 `great-circle-width-v1`：左右虚拟声源沿中心的水平切向作正负半宽大圆偏移，避免高仰角和天顶处的宽度坍缩；FOA、扬声器馈送、HRTF及宽度显示采用同一几何。旧导出缺少当前几何版本时需重渲染，旧文件保留并在重建时隔离保存；旧页面需刷新后重新渲染HRTF。此更新不改写已有场景或原始音频。

## 显式宽广候选（0.8.2）

`mix/apply` 的 `layout: "spacious"` 与原 `content`、`preserve`、`anchored` 独立。使用同一份绑定分析与已处理轨，仅改空间位置、宽度与明确分类轨的静态轨迹，不改变轨PCM、gain、mute、EQ、压缩、几何版本或共同峰值保护。沿用原预览和恢复流程；应用静态候选会替换明确分类对象的已有运动，恢复可取回此前场景。

低频占比至少0.5的对象和显著残差载体继续前方耳平面。有效非低频主体（相对RMS至少0.7）保持前方±30°、宽度至少60°；其他有效前方对象在±45°、宽度至少60°。只有场景增益后的RMS高于0.001、相对RMS不超过最强有效活动对象0.65、活动比例至少0.5、crest不超过20 dB且非低频/残差的真实陪衬对象，才放在原侧对应±115°、仰角30°、宽度至少75°。Side不作为单声道陪衬的强制条件。已有更大宽度不收窄。静音、无效/缺失测量或活动比例低于0.25的对象不作展开；弱轨不提增益、不造运动或混响，LFE继续无节目。

报告记录`layout`、`thresholds`、逐轨保护原因和`expandedObjectCount`（实际侧后/高度候选数）。没有安全陪衬时明确警告，不以全12声道非零为目标。这些门槛是可审计项目启发式，不是乐器识别或听感最优证明。位置变化仍可能改变相干叠加、峰值保护衰减和主体感；需比较等响度空间听感与实际输出力度，不能用能量/响度统计代替耳机及真实房间听辨。

## 回归与试听

内容保持但ID或观测顺序变化时角色一致；安静/缺失/非有限观测不作强推断；Side、低频主体及显著残差受保护；场景参数有限合法；旧手动场景可恢复。运行相关Python/Node检查、浏览器真实播放与布局检查。新交付独立保存，源文件哈希不变。耳机听辨、真实7.1.4路由/房间校准及Atmos母版仍分别验收。
