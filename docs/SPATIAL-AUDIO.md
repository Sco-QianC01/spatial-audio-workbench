# 空间音频工作台

本项目是独立的本地混音与空间音频应用。安装、独立 `.venv`、权重、FFmpeg 与启动命令以 [README](../README.md) 为准。本页描述当前制作合同，不把来源项目的历史机器验收当成新安装已经通过。

## 两条明确入口

- `native-stems-first-v1`：优先导入 2–12 条原生声部的无损分轨 ZIP，包含生成回执及统一时间线。生成端须实际支持 ACE Base/lego；当前服务能力须另行确认，失败不会自动改走分离。
- `separated-stereo-v1`：手动导入立体声后点击本地分离，或对线上结果明确点击“下载并本地分离”。使用本地 torchaudio HDemucs 与已提供的权重，生成四组估计声部。导入、页面重载和旧任务回执不自行启动分离。

两条路线的详细格式、生成器和重试约束见 [分轨制作入口](SPATIAL-STEM-ROUTES.md)。线上生成是可选的外部集成，需要可访问的既有服务；不影响本地文件路线。下载与工程路径由启动参数配置，没有绑定开发者机器的默认素材路径。

## 混音与自动化

分析会测量响度、真峰值、声部活动和频段，并形成透明规则提案。候选保留原始来源及处理记录；原版与候选采用可用的等响度副本进行 A/B。测量不可用时不能把空值视为通过，短音频的 LRA 不用作动态评价。

处理不会自行应用到声场。明确应用后可保留当前布局与轨迹，或选择内容适配等静态候选。内容适配依据电平、频段和 M/S 观测，不把分离器 ID 当作已确认乐器，不保证每首曲都使用环绕或顶部。详见 [内容适配](SPATIAL-CONTENT-MIX.md)。

界面以中性编号显示轨道，来源 ID 保留在工程记录。选择轨道后编辑增益、宽度、方位、仰角及关键帧。时间以秒为单位；每轨轨迹支持 2–32 点，首尾固定于音频时间线，角度逐段按最短弧插值。切换工程会尝试保存当前编辑，服务失败或冲突时中止切换；关闭页面前仍应确认最新修改已保存。

修改关键帧时间会同步试听与游标。A/B 音频尚未加载完成时，选择其他试听会取消旧的自动恢复播放，防止迟到的加载回调抢播。

混音候选在列出、复用、应用和下载前检查报告绑定、音频格式与长度、已有来源哈希和比较包完整性。缺失或损坏的候选隐藏且不占用两个候选额度；重新处理相同提案时保留旧目录，再发布完整结果。此校验不代替完整听辨，也不将存在的旧报告当作所有音频内容均未变的证明。后台任务在项目保存或临时文件清理失败后仍释放工作锁，并显示失败，修复磁盘或权限后可重试。

## 方向与输出

- 方位 0° 向前，+90° 向左，-90° 向右，±180° 向后；仰角 +90° 向上。
- 立体声宽度使用 `great-circle-width-v1`，左右声源沿中心方向的水平切向分别偏移半宽，避免天顶宽度塌缩。
- FOA 使用 48 kHz、ACN `W,Y,Z,X` 与 SN3D（AmbiX）；不能当作普通四声道节目播放或计量。
- 支持 5.1.2 与 7.1.4。7.1.4 通道顺序为 `L R C LFE Ls Rs Lrs Rrs Ltf Rtf Ltr Rtr`，节目 LFE 默认静音，主通道保留低频。
- 棚内包提供 12 条对齐工程零点的 48 kHz PCM24 mono WAV、路由识别音、CSV 与报告。共同尾段为 0.25 秒。轨迹已烘焙入文件，一轨直送一路经确认的硬件输出。
- 双耳试听使用浏览器通用 HRTF，不是个体化测量；扬声器通道可独立于浏览器 HRTF 渲染。修改声场后旧导出失效，应重新渲染。

双耳发布与下载会核对实际 WAV 的 SHA256 和质量回执；文件内容改变后停止提供该版本的双耳音频、报告与包，健康的扬声器导出和旧双耳版本仍可使用。哈希与 ZIP 校验按文件时间戳及大小缓存，文件变化后重新检查。

完整工程包、棚内包及双耳文件有不同用途，具体文件合同见 [棚内逐通道交付](SPATIAL-STUDIO-HANDOFF.md)。这些输出不包含 Atmos ADM 对象元数据，不是 ADM BWF 或 Dolby Atmos 编码/认证母版。

## 验证范围

Node 测试覆盖轨迹、自动化、播放器、三维合同与生成界面；Python 空间套件覆盖分离、原生导入、混音、渲染与路由等合同。CI 不执行真实模型生成，不下载模型或素材，不验证真实设备。

实际音乐须逐轨与合听检查串音、瞬态、相位、起止同步和移动轨迹。棚内需校准通道映射、电平、极性、延时及低频管理。macOS 安装、个体 HRTF、声卡、扬声器与房间均不得仅凭自动测试标记为完成。
