# 逐轨空间 Automation

导入同步分轨，或明确选择从立体声进行本地分离。每条直接轨独立保存方位角和仰角；空间坐标使用同一音频时间轴，不分析或猜测原录音的实际声源位置。

## Write 与 Read

1. 选中一条轨道，点击 **Write**。首次使用会读取当前声部，并准备实时空间监听。
2. 点击播放。在三维视图拖动选中的声源球，或在二维精确面板、方位／仰角推子上移动。拖动三维空白仍用于旋转观察视角。
3. 暂停会结束本次写入、切回 **Read** 并自动保存。页面显示“轨迹已保存”后再关闭。写入期间点击撤销可放弃本次录制，原轨迹保持；完成后的修改也支持撤销／重做。
4. 换另一轨重复录制，已完成的其他轨道保持。Read 播放时所有轨道按各自轨迹一起重放，暂停、继续和跳转使用实际音频位置。
5. 需要文件时，选择扬声器布局并渲染。实时监听、HRTF 离线试听与扬声器导出读取同一份场景轨迹。7.1.4 逐通道包可用于棚内按路由清单复核。

首次 Write／Read 会自动选择“空间监听 · 实时”。“原曲参考”和“分轨参考”保留原本的立体声参考，不跟随空间轨迹。离线 HRTF 试听在参数修改后失效，需要重新渲染。

## 写入与保存规则

- 以音频 `currentTime` 记录，目标间隔 50 ms；时间点按毫秒存储。浏览器卡顿可能使实际间隔变长，不能视为精密运动捕获或采样级同步。
- 每轨最多 12002 个关键帧，支持当前最长 600 秒音频的完整 20 Hz 录制。结束时简化重复／近似直线部分，采样点的方位与仰角误差上限为 0.25°；这不代表感知定位精度。
- 方位在相邻点之间沿最短角插值，跨越 ±180° 保持连续。整圈移动需要中间点，不能只用两个同方向端点表达。
- 首次录制没有轨迹的轨道，开始前保留原方向，停止后将最终姿态保持至音频结束。
- 修改已有曲线时，从中途开始／结束 Write 只替换本次时间区间。前后保留原曲线，并在边界以最多 1 ms 的保护间隔恢复原曲线；如果两次位置相差很大，需手动补过渡，避免突变。
- 合并超过关键帧上限会拒绝替换原曲线，保留未完成 take 并显示错误；可用撤销放弃本次写入。保存冲突或服务断开不会静默覆盖已有工程。
- 写入时暂停、播放到末尾会结束录制；跳转会先结束本次写入，再重新定位和进入 Write。实时监听页转到后台会暂停，避免后台刷新节流造成位置停滞。
- Write 时锁定会改变时间线或渲染源的操作。播放前确认轨道、模式和起点；本轮不提供音量、效果器或距离的 Automation。

## 监听与输出

实时监听将立体声声部的左右声道分别送入通用 HRTF，使用与导出相同的方向和宽度约定；位置参数使用 15 ms 平滑，减少拖动时的突变。各声部从同一 Web Audio 时钟与偏移位置启动，缓冲等待后重新对齐媒体时钟。

实时监听使用由 PCM 峰值推导的保守整体衰减，不是成品响度匹配或真峰限制器。浏览器 HRTF、声卡、耳机和用户头部差异会影响听感；实时与离线调度也不保证逐采样一致。最终文件另走既有离线质量检查，不通过提高音量证明空间更好。

方向约定：前方 0°、左方 +90°、右方 −90°、上方 +90°。三维球表示方向参照，不表示房间实测距离。扬声器布局没有下方扬声器时，下半球方向按现有规则投影到水平。LFE 默认静音，完整低频保留在主声道。

输出为双耳 WAV、AmbiX、扬声器馈送和场景 JSON；不要求或生成 Dolby Atmos ADM。实际空间感、原声音色与力量感须试听，棚内通道接线与声压仍需现场验证。
